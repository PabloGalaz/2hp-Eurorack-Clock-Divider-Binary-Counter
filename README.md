# 2hp-Eurorack-Clock-Divider-Binary-Counter
Slim CD4024-based Eurorack Clock Divider/Binary Counter
Schematic based on Clock Divider by PolyKit (https://polykit.rocks/eurorack-clock-divider-module-modular-synth-diy/), with the following differences:
- 2hp (instead of 4hp)
- Mostly SMD components (0603)
- Added /128 output
- Added LED for clock input (through hole, bended)
- Only one board

  The PCB layout was inspired by the PCB layout of Uncertainty, by OAM (https://github.com/oamodular/uncertainty.git)

  First version has a footprint error that can be fixed by bending carefully the legs of the 1N4148 (SOD-123) and soldering them upside down (!). It's easier that it sounds like, and it will work. Version 2 has that error fixed, but has not been tested.
